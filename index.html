    How to get the token

    On github.com open Settings, Developer settings, Personal access tokens, Fine-grained tokens, then Generate new token. Choose only your Shorts repository, and under Repository permissions set Contents and Actions to Read and write. The token stays in this browser only and is sent only to GitHub.
