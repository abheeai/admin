    Token permission needed for saving defaults

    Saving the daily default stores three settings in your repo (KIDS_MUSIC, KIDS_MUSIC_TRACK and KIDS_MUSIC_LEVEL). Your GitHub token needs Variables set to Read and write, as well as Contents and Actions. If saving fails with 403, edit the token on GitHub and add that permission.

      Use this panel on other devices (password lock)

      Lock your token with a password. The locked copy is saved as vault.json next to this panel. On any other device, open the panel and type the password, with no token to paste. Without the password the locked copy is useless, but because it sits on a public page, use a long password: at least 12 characters, a short phrase works well.

      1. Tap Copy to copy the locked file:
      2. Tap Open GitHub. It opens a new file called vault.json in the repo where this panel lives. Paste into the big box (replace anything there) and tap Commit changes.
        Open GitHub (new file)Already have vault.json? Edit it
      3. After a minute, open the panel on your other device. It will ask for the password.

      How to get the token

      The Setup tab, step 1, walks you through it with buttons. To avoid pasting it on every device, use the password lock above. In short: on github.com open your profile picture, Settings, Developer settings, Personal access tokens, Fine-grained tokens, then Generate new token. Choose only your youtube repository, and under Repository permissions set Contents, Actions and Variables to Read and write. The token stays in this browser only and is sent only to GitHub.
